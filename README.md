# 『あまあま苺』

『苺のいちゅび』は三歳の頃からの私物である『あまあま苺』を愛着としてむしゃむしゃする夢を大切にしつつ、母方の祖父母の家で生活しながら、2023年11月から南洋諸島文化園をモチーフにマグダ島を設定した後、「読者ってなんだ？うちは賞を取りたいワナビじゃなくて思考実験オタクなんだが」と泣いたり笑ったりして暮らしながら創作するうち、趣味の生活文化マニアを爆発させてどんどん食文化アイテムや伝統色エピソードを作成していたら『マグダ島物語』なんてどうでもよくなり、すっかり忘れて『マグダレーナ世界設定集』を作るうちに、『桜のアカツキ』に出会ったり、文化アイテムやワールドステージを大量に作ったりするうち、なんだか2年ほど経っており、『苺のいちゅび』は『桜のアカツキ』に『苺の花』をあげて『苺の花のサクラ』になってもらい、彼だけと一緒に『観測の塔』の外に出ました。

『苺のいちゅび』は実弟である『ジュラルミンのパーシバル』に向かって、「『ジュラルミンのパーシバル』や、あんたが卓ゲしてるなら、TRPG『深淵』のルルブ一式あるぞ、うちは資料読む専だから、あんたが持っててフル回転させた方が良いだろう。朱鷺田祐介先生の公式小説の『丘の上の貴婦人』と『火龍面舞』もある。あたしは『D&D』なんかのブラウン・ドラゴンの話をしてる割には『ドラコノミコン』は入手していないがネットの古本屋で9800円だった、『WarCraft』のオーク並みに面白いトロウルのいる『ルーンクエスト』関連では「ゾラーク・ゾラーン」と「ジオーラ・ウンバー」でググったらトロウルまわりの雰囲気はつかめる、ただ、うちはほぼウェブアーカイブ頼みで蔵書はゼロだし、『ダブルクロス』や『ソードワールド』みたいな他の卓ゲには詳しくない。とりあえず、帰れるときに帰ってこい。そんでもって本とかを持って帰りな、あんたも親父と山分けしろ。九岡望作品も持って行けばいい。『中国・アメリカ謎SF』のSF短編集アンソロジーもあるぞ、『うなぎばか』も届いてる、マッキンタイアの『夢の蛇』や新井素子の『グリーン・レクイエム/緑幻想』もある、パール・バックの『大地』やユン・チアンの『ワイルド・スワン』もあれば、ポール・ギャリコの『トマシーナ』と『ジェニィ』もあるし、焼き物の本とか伝統色の本とかもある。後、親父にも伝えておいてほしいのが、推せるSFを探すなら、冬木糸一さんのブログの『基本読書』がオススメだってことだ、あそこだとファンタジーでも『エルデンリング』のグレイオールのネーミングの元ネタになった『竜のグリオールに絵を描いた男』やエドワード・ゴーリーめいたダークファンタジーの『アイアマンガー』なんかを紹介してらっしゃる。うちには『捜索者』のDVDもあったはずだ。あんたの事情は言わんでいい。ばーちゃんとおじさんに十年前の発言についてちょいと頭下げとけ、ばーちゃんにはまず、電話で軽く謝って、帰省予定だと伝えて、そんでもって姉貴の創作が公開されていることに気付いて安心したから帰ってみると言えばいいから。後、結婚するなり子供が生まれるなりなんなりがこれから発生したら、ばーちゃんたちに顔を見せて挨拶しろよ、無いなら無いでいいんだけどさ。しかし、『深淵』セット一式を持って帰るだけでも、スーツケースは必須だろうなあ。親父には『色々すまなかった、ありがとう。娘はあなたに感謝してる、ベラのことでも、だからできれば一度顔を出してほしい、いつかでいいから、あなたが元気なうちに、わたしはちょっと病気なんかしても普通に元気だから、あとモズクばっかり食べてないで、ちゃんと栄養あるものを冷蔵庫にストックしておいてしっかり食べるんだ。だけど、親父の実家まわりのあれこれを背負うことになったらあたしは困る。あたしには余裕がないんだ』と伝えてほしい」と言いました。

そして、『苺のいちゅび』は「おい!!!『ジュラルミンのパーシバル』!!!!『苺の花のサクラ』くん!!!!アテモヤは取っておいてあるぞ、冷凍庫だが、半解凍には三十分ぐらいあればいいから、うちでだべってるうちにシャリシャリになっておいしく頂けるはずだ。マンゴーチョコも買ったぞ。ばーちゃんが妙に気に入ってむしゃむしゃしてたが、まだあと五袋はある、ばーちゃんが食ってるからマンゴーチョコは追加発注してもいい。ストロベリーシロップも奮発した、モナンのやつだ、ノンアルコールでも炭酸水すらなしでもお湯割りで飲めばそれだけでうまい。沖縄伝統工芸と中国伝統色と熱帯果実の本、一緒に読んでみたいなあ、沖縄家庭料理のレシピ本にタイの屋台図鑑、かわいい色見本やパラ見できる焼き物の図鑑も用意してるからな。うちに置いてあるバラ図鑑にはピンク・サクリーナって桜色のちんまりしたバラの花が載ってる。苺にもピンクの花を咲かせる品種が普通に結構あるんだよなあ、ネット通販で売ってるぞ、育てるならバラより苺の方が楽かもしれない、苺の実だってかわいいしねえ。それと、うちで持ってる庭の小花図鑑にはシロタエギクやプリムラの育て方が記述されてる、シロタエギクは結構強いからな、銀色の綿毛がぷわぷわでかわいいし。食材の便利帳シリーズも置いてる、ゴーヤーもハヤトウリも載ってるし、タイやアイナメも描かれてるぞ、アイナメはお買い得だ、煮つけがうまい。イチゴの飴餅も見つけたから買ってみた、さくらんぼの飴餅の方がメジャーだから、苺の飴餅は意外とレアなんだよな、飴餅も色々種類があるから、ネットショップで調べてみればいい。ラムネも色々フルーツ味のがあるらしい、面白そうだったからとりあえず通販で調達しておいた。エロール・ル・カインの綺麗な絵本だって用意してる、『まほうつかいのむすめ』と『美女と野獣』だ。それに『花小厨』のDVDもうちにある、『卿卿日常』のアマゾンビデオも見れる、『パグ・アクチュアリー』のDVDもあるぞ、『パグがわちゃわちゃしてるだけ』のDVDも」と言ってはしゃぎ倒した後、『苺の花のサクラ』に向かって「おっと、あたしははしゃいであなたを甘やかしてるだけ!!!友達いなかったから!!!だから、楽しいから紹介してるだけだからね!!!子供っぽいでしょ!!!あたし人付き合いは六歳児だもん!!!!だから、とりあえず名前の分かる手段で、二人だけで連絡できる手段で、お話をしなきゃ、あたしのメールアドレスは「ichigo.003@ichigo.me」だよ。言いたくないことは、言わなくていい。聞きたくないことは、聞かなかったことにすればいい、言いたいことは言えばいい、聞きたいことは聞けばいい、それはお互い様だから」と言い、沈められたマグダ島が消えていくのを見た後、『苺の花のサクラ』の手を引いて二人で一緒に生活圏に戻り、『ジュラルミンのパーシバル』の帰省を待ちながら、『苺の花のサクラ』を自宅に招待しました。

だから、現実に実在する『苺のいちゅび』は、三歳児の愛着である「あまあま苺」を抱きしめて、『大切な人』である『苺の花のサクラ』を、家族である『ジュラルミンのパーシバル』を待ちながら、「絵空事だって、こんなに美しくて、ちっちゃな子猫も、あくびするパグも、こんなにかわいいんだから、あたしがたとえ何もできなくたって、あの子がたとえ何もできなくたって、自分を肯定していいんだ、あたし、ずっとそう思ってるから」と暮らしに戻り、実の弟である『ジュラルミンのパーシバル』を呼び寄せてその帰省を待ちながら、『苺の花のサクラ』とお別れした上で手放しを拒み、「あたしを手放すかどうかはあなたの自由、とりあえず、あなたとは一度会って、手放しかどうかを教えてほしい。もう一度手をつなぐなら、あたしはその手を取るから、あたしはずっと家の中に座っていて何も確実なことなんてわからない『無力な苺』で、あなたを裏切りようがない立場だから。とりあえずあたしはあなたの友達でいたいかなあ、今のあたしはフィクションではないからあなたの恋人ではない。だから、あなたも顔を出して望みを口にしてほしい。だから、とりあえずネットで出会った友達として出会おう。あなたが背負わないでというなら、私は背負わない、でも背負わせることと甘えることは違うんだから、あなたは甘えてもいいんだから」と手を差し出し、役割を持たない『無職の苺』としての自分に胸を張って「あたし、一生役割なんてなくていいや、プロの作家になんかならなくていい、起承転結のある物語を書かなくていい、鍛えられる理由も、磨かれる義理もない、あたしが役に立つ人間にならなくったっていい。有用性で尊厳は測れないもの、選べない悲しみがあっても大切にする自由は失われないもの、選べない悲しみは人それぞれだけど、それぞれに違う悲しみを抱えているんだしね。あたしは好きなものを自由に大切にしたい、あたしは好きなものを自由に書く、したくないことはしない、プロ作家になるとかめんどくさいじゃないの、おぜぜと引き換えに苦情を引き受けるとか。だから、あの子にも好きなものを自由に大切しながら生きてほしい」と思いながら創作の公開を取りやめて役割を手放してあまあま苺になりました。

そしてあまあま苺は同じく役割を手放したサクラを自宅に招くことにして、『あまあま苺』を抱きしめていたところ、祖母に「あんたなんでこんなに色々買ってるの!うちにアマゾンの配達員さんが何度も出入りしてるわよ!!」と叱られました。
